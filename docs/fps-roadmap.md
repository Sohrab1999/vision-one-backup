# 🎯 نقشه راه جامع تحول «شوتر آموزشی اول‌شخص» — ۱۴۰۵

> مرجع اصلی تحول `fps-shooter-game.tsx`. قانون طلایی: **آموزش در قلب شلیک** — هر فاز باید هم حس شوتر واقعی بدهد و هم یادگیری واژه/گرامر را عمیق‌تر کند.
> قرارداد: هر بار فقط یک فاز؛ پایان هر فاز = تیک + خلاصه در `worklog.md` + QA مرورگری + `bun run lint` صفر.

## 🧭 فلسفه طراحی

1. **بگرد، پیدا کن، شلیک کن** — بازیکن آزادانه در میدان می‌چرخد و قدم می‌زند؛ پاسخ درست خودش را نشان نمی‌دهد.
2. **سلاح = ابزار تمرکز** — recoil، خشاب، ریلود و صدای برخورد هر شلیک را «باارزش» می‌کنند؛ شلیکِ شتاب‌زده جریمه دارد.
3. **صفر درد performance** — چانک lazy جدا برای three.js؛ کیفیت سبک برای گوشی؛ صدا فقط در لحظهٔ رویداد.
4. **دسترس‌پذیر مثل بقیه اپ** — تپ ساده، کلیدهای ۱..۴، aria-live، reduced-motion.

## ✅ فازهای تکمیل‌شده

### F1 — تولد شوتر سه‌بعدی ✓
- میدان low-poly با three.js/R3F: زمین، کوه، اجسام شناور، مه و نور.
- دو حالت: «شکار واژه» (معنی فارسی → شکار واژهٔ انگلیسی) و «سد گرامری» (تست گرامر).
- هدف‌های اوکتاهدر متحرک با بیلبورد گزینه + انفجار رنگین‌کمانی InstancedMesh.
- اتصال آموزشی کامل: Attempt، رکورد per-scope، صف مرور هوشمند، تلفظ TTS پاسخ درست.

### F2 — کیت استاندارد بازی‌ها (G2-e) ✓
- GameShell یکنواخت + توقف/ادامه با فریز واقعی حلقهٔ R3F + جبران دقیق تایمرها.
- صدا/لرزش سینتتیک فقط در لحظهٔ رویداد (شلیک/برخورد/پایان/رکورد)، بی‌صدا سراسری.
- کیفیت گرافیک عادی/سبک (dpr، antialias، ذرات، تعداد هدف ۴→۳) با ماندگاری انتخاب.
- آموزش ۳گامی + نگهبان خروج + تله‌متری جلسه + کمبوی موتور مشترک کیت.

### F3 — اول‌شخص واقعی ✓
- **تمام‌صفحهٔ خودکار** با «شروع مأموریت» (Fullscreen API + فال‌بک webkit؛ خروج خودکار در پایان/خروج).
- **تفنگ سه‌بعدی ویومدل**: همگام با دوربین بدون parenting، sway تنفسی، باب گام، recoil از رویداد شلیک، جرقهٔ دهانه + نور لحظه‌ای.
- **حرکت WASD/جهت‌نما** با e.code (مستقل از کیبورد فارسی)، باب سر، محدودهٔ امن میدان.
- چیدمان «جست‌وجو»: لِین‌های عریض ±۶٫۸ و عمق پخش ۵٫۵–۱۲.

### F4 — کنترل حرفه‌ای موبایل + مکانیک خشاب ✓ (این فاز)
- **خشاب ۸تایی**: شمارندهٔ مهمات (هدر شِل + چیپ داخل قاب + روی دکمهٔ شلیک)، ریلود خودکار پس از خالی شدن، R روی دسکتاپ، صدای کلانک تعویض، چرخش آیکون حین ریلود.
- گیت‌های شلیک: حین ریلود/فریز برخورد/توقف مهمات هدر نمی‌رود — شلیک «باارزش» شد.
- **جوی‌استیک لمسی چپ** (pointer:coarse، خارج از تپ ساده): بردار آنالوگ با deadzone و سرعت متناسب کمان، مستقیم در SceneBridge (صفر ری‌رندر).
- **دکمهٔ شلیک راست موبایل**: شلیک از رتیکل مرکز؛ تپ روی هدف همچنان کار می‌کند.
- **افکت پوکهٔ برنجی**: پرتاب از پورت خروج با گرانش/اسپین/محو + صدای «تاک» برخورد گلوله.
