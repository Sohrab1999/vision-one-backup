# 🎯 نقشه راه جامع تحول «شوتر آموزشی اول‌شخص» — ۱۴۰۵ (نسخه ۲.۰)

> مرجع اصلی تحول `fps-shooter-game.tsx`. قانون طلایی: **آموزش در قلب شلیک** — هر فاز باید هم حس شوتر واقعی بدهد و هم یادگیری واژه/گرامر را عمیق‌تر کند.
> قرارداد: هر بار فقط یک فاز؛ پایان هر فاز = تیک + خلاصه در `worklog.md` + QA مرورگری + `bun run lint` صفر.

## 🧭 فلسفه طراحی

1. **بگرد، پیدا کن، شلیک کن** — بازیکن آزادانه در میدان می‌چرخد و قدم می‌زند؛ پاسخ درست خودش را نشان نمی‌دهد.
2. **سلاح = ابزار تمرکز** — recoil، خشاب، ریلود و صدای برخورد هر شلیک را «باارزش» می‌کنند؛ شلیکِ شتاب‌زده جریمه دارد.
3. **صفر درد performance** — چانک lazy جدا برای three.js؛ کیفیت سبک برای گوشی؛ صدا فقط در لحظهٔ رویداد.
4. **دسترس‌پذیر مثل بقیه اپ** — تپ ساده، کلیدهای ۱..۴، aria-live، reduced-motion.

## ✅ فازهای تکمیل‌شده

### F1 — تولد شوتر سه‌بعدی ✓
- میدان low-poly با three.js/R3F: زمین، کوه، اجسام شناور، مه و نور.
- دو حالت: «شکار واژه» (معنی فارسی → شکار واژهٔ انگلیسی) و «سد گرامری» (تست گرامر).
- هدف‌های اوکتاهدر متحرک با بیلبورد گزینه + انفجار رنگین‌کمانی InstancedMesh.
- اتصال آموزشی کامل: Attempt، رکورد per-scope، صف مرور هوشمند، تلفظ TTS پاسخ درست.

### F2 — کیت استاندارد بازی‌ها (G2-e) ✓
- GameShell یکنواخت + توقف/ادامه با فریز واقعی حلقهٔ R3F + جبران دقیق تایمرها.
- صدا/لرزش سینتتیک فقط در لحظهٔ رویداد (شلیک/برخورد/پایان/رکورد)، بی‌صدا سراسری.
- کیفیت گرافیک عادی/سبک (dpr، antialias، ذرات، تعداد هدف ۴→۳) با ماندگاری انتخاب.
- آموزش ۳گامی + نگهبان خروج + تله‌متری جلسه + کمبوی موتور مشترک کیت.

### F3 — اول‌شخص واقعی ✓
- **تمام‌صفحهٔ خودکار** با «شروع مأموریت» (Fullscreen API + فال‌بک webkit؛ خروج خودکار در پایان/خروج).
- **تفنگ سه‌بعدی ویومدل**: همگام با دوربین بدون parenting، sway تنفسی، باب گام، recoil از رویداد شلیک، جرقهٔ دهانه + نور لحظه‌ای.
- **حرکت WASD/جهت‌نما** با e.code (مستقل از کیبورد فارسی)، باب سر، محدودهٔ امن میدان.
- چیدمان «جست‌وجو»: لِین‌های عریض ±۶٫۸ و عمق پخش ۵٫۵–۱۲.

### F4 — کنترل حرفه‌ای موبایل + مکانیک خشاب ✓ (این فاز)
- **خشاب ۸تایی**: شمارندهٔ مهمات (هدر شِل + چیپ داخل قاب + روی دکمهٔ شلیک)، ریلود خودکار پس از خالی شدن، R روی دسکتاپ، صدای کلانک تعویض، چرخش آیکون حین ریلود.
- گیت‌های شلیک: حین ریلود/فریز برخورد/توقف مهمات هدر نمی‌رود — شلیک «باارزش» شد.
- **جوی‌استیک لمسی چپ** (pointer:coarse، خارج از تپ ساده): بردار آنالوگ با deadzone و سرعت متناسب کمان، مستقیم در SceneBridge (صفر ری‌رندر).
- **دکمهٔ شلیک راست موبایل**: شلیک از رتیکل مرکز؛ تپ روی هدف همچنان کار می‌کند.
- **افکت پوکهٔ برنجی**: پرتاب از پورت خروج با گرانش/اسپین/محو + صدای «تاک» برخورد گلوله.

## 🔮 فازهای جدید — سه‌گانهٔ «گزینه‌ها، نقشه، محیط» (نسخهٔ ۲.۰ سند)

> درخواست کاربر ۱۴۰۵-۰۸-۲۱: «نقشه راه را بروز کن و برای گزینه‌ها و نقشه و محیط برنامه». سه فاز F5/F6/F7 به‌صورت یک بستهٔ هم‌پیوند طراحی شدند: **گزینه‌ها** احساس کنترل می‌دهد، **نقشه** تنوع بصری می‌دهد و **محیط** میدان را از «صف اهداف» به «دنیای قابل‌گردش» تبدیل می‌کند.

### F5 — گزینه‌ها و شخصی‌سازی ✓ (این فاز)
- [x] **حساسیت نگاه** (اسلایدر ۴۰٪ تا ۲۲۰٪) — روی موس دسکتاپ و کشیدن لمسی هم‌زمان اثر می‌گذارد؛ ماندگار در `visionone:game-pref:fps-sens`.
- [x] **زاویهٔ دید (FOV)** (اسلایدر ۶۲ تا ۹۶ درجه) — حین بازی هم زنده اعمال می‌شود (updateProjectionMatrix)؛ ماندگار در `visionone:game-pref:fps-fov`.
- [x] **وارون‌سازی عمودی (Invert Y)** — سوییچ؛ برای بازیکنانی که با کنسول عادت دارند؛ ماندگار در `visionone:game-pref:fps-invert`.
- [x] **پنل گزینه‌ها در setup** + **تنظیمات سریع داخل اورلی توقف** (اسلایدر حساسیت + وارون‌سازی بدون خروج از دور).
- [x] مقادیر با `faNum` فارسی و aria-label کامل؛ انتخاب‌ها به `detail` تله‌متری/Attempt افزوده می‌شود (افزودنی — امضاها دست‌نخورده).
- معیار پذیرش: تغییر اسلایدر بلافاصله در چرخش موس محسوس است؛ ری‌استارت صفحه تنظیمات برمی‌گردد؛ کنسول صفر.

### F6 — نقشه‌های مأموریت ✓ (این فاز)
- [x] **۳ نقشهٔ انتخابی در setup**: «جنگل زمردی» (کلاسیک سبز)، «کویر کهربا» (غروب شنی با خورشید بزرگ) و «سکوت شب» (آسمان پرستاره + ماه + کریستال‌های درخشان).
- [x] هر نقشه پالت کامل خودش را دارد: رنگ پس‌زمینه/مه، زمین، حلقه‌های راهنما، کوه‌ها، اجسام تزئینی، نور hemisphere/directional و بدنهٔ قاب (wrap).
- [x] نقشه‌های «شب» اجسام emissive درخشان دارند تا هدف‌ها در تاریکی خوانا بمانند (خوانایی آموزشی قربانی زیبایی نمی‌شود).
- [x] انتخاب ماندگار در `visionone:game-pref:fps-map` + کارت‌های نقشه با نمونه‌رنگ (swatch) و توضیح + `detail.map` در Attempt.
- [ ] آینده: نقشهٔ چهارم «برف قطبی» با مه سنگین + بازتاب، و چرخش تصادفی نقشه در حالت «میکس».
- معیار پذیرش: هر ۳ نقشه شروع‌به‌کار کامل، بدون افت فریم محسوس، انتخاب بعد از reload پابرجا.

### F7 — محیط زندهٔ میدان ✓ (این فاز)
- [x] **عناصر پوشش (Cover)**: جعبه‌های چوبی و ستون‌های ابلیسک دو طرف میدان — کدرِ draw پایین، خارج از خط دید هدف‌ها (فقط دکور؛ رِی‌کست شلیک دست‌نخورده).
- [x] **پراکندهٔ زمین**: سنگ‌ریزه‌های dodeca و بوته‌های مخروطی — میدان دیگر «صف خالی» نیست، عمق دارد.
- [x] **آسمان زنده**: ابرهای low-poly چرخان (جنگل/کویر)، آسمان پرستاره (نقشهٔ شب)، خورشید/ماه درخشان با هاله.
- [x] بودجهٔ پرفورمنس: تعداد عناصر محیطی در «کیفیت سبک» و دستگاه ضعیف خودکار کم می‌شود (سه ترتیب full/weak/low).
- معیار پذیرش: روی ۳۹۰px و کیفیت سبک بدون افت محسوس؛ عناصر محیطی هیچ‌کدام در مسیر raycast هدف‌ها نیستند.
