# §F) اصلاحات میانی مأموریت (ثبت شفاف)
1. **merge کلید چندصفحه‌ای** — کلید درس‌هایی مثل درس ۴ در دو صفحهٔ Answer key پخش است؛ نگاشت `unit→answers` از «اولین صفحه» به «ادغام کامل» اصلاح شد (در extract و build).

4. **gزینه‌های بدون ساختگی** — اولویت استخر فریب‌دهنده: بانک چاپی تمرین > واژه‌های متمایز Answer key همان تمرین (طبیعی برای تمرین‌های دسته‌بندی مثل 1.5) > واژگان همان درس — هرگز واژهٔ بیرونی.
