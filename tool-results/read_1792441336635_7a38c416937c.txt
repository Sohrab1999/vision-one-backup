   321→  /** یکپارچگی آزمون با SRS (فاز ۲): واژهٔ غلط‌زدهٔ واژگانی به صف مرور برمی‌گردد */
   322→  function seedVocabReview(correctOption: string | undefined) {
   323→    if (!correctOption || !bookData) return;
   324→    const exact = bookData.vocab.all.find((v) => v.word === correctOption);
   325→    const loose = exact ?? bookData.vocab.all.find((v) => correctOption.includes(v.word));
   326→    if (loose) seedReviewFromQuiz(loose.word);
   327→  }

   329→  function chooseOption(optIdx: number) {
   330→    if (selected !== null) return;
   331→    if (timed > 0 && deadlineRef.current > 0) {
   332→      answeredLeftRef.current = Math.max(0, Math.ceil((deadlineRef.current - Date.now()) / 1000));
   333→    }
   334→    setSelected(optIdx);
   335→    setAnswers((prev) => {
   336→      const next = [...prev];
   337→      next[index] = optIdx;
   338→      return next;
   339→    });
   340→    if (current) {
   341→      if (optIdx === current.answer) {
   342→        // کیت بازی‌ها — بازخورد صوتی/لرزشی پاسخ درست
   343→        playSound("correct");
   344→        buzz("success");
   345→        // در مرور اشتباهات و مرور ترکیبی، پاسخ درست سؤال را از دفتر اشتباهات حذف می‌کند
   346→        if (mode === "review" || mode === "combined") resolveMistake(current.id);
   347→      } else {
   348→        // کیت بازی‌ها — بازخورد صوتی/لرزشی پاسخ غلط
   349→        playSound("wrong");
   350→        buzz("error");
   351→        recordMistake(current.id);
   352→        if (current.category === "vocabulary") seedVocabReview(current.options[current.answer]);
   353→      }
   354→    }
   355→  }

   385→  /** ساخت یک تست مشابه از سؤال جاری با هوش مصنوعی — نمایش به‌صورت کارت بونس */
   386→  async function generateSimilar(fromBonus = false) {
   387→    if (!current || bonusLoading) return;
   388→    // «سؤال مشابه بعدی» از روی سؤالِ مشابهٔ فعلی زنجیر می‌شود (تولید بی‌نهایت)؛
   389→    // دکمهٔ اصلی همیشه از سؤال اصلی منبع می‌گیرد (تکرار همان سؤال → پاسخ کش‌شده).
   390→    const src = fromBonus && bonus ? bonus : current;
   391→    setBonusLoading(true);
   392→    try {
   393→      const res = await fetch("/api/similar-question", {
   394→        method: "POST",
   395→        headers: { "Content-Type": "application/json" },
   396→        body: JSON.stringify({
   397→          text: src.text,
   398→          options: src.options,
   399→          answer: src.answer,
   400→          category: current.category,
   401→          book: {
   402→            id: bookId,
   403→            title: bookData?.info.title ?? "",
   404→            grade: meta?.gradeLabel ?? "",
   405→          },
   406→        }),
   407→      });
   408→      const data = await res.json();
   409→      if (!res.ok || !data.question) {
   410→        toast.error(data.error ?? "سؤال مشابه ساخته نشد — دوباره تلاش کن");
   411→        return;
   412→      }
   413→      setBonus(data.question as SimilarBonus);
   414→      setBonusSelected(null);
   415→      setBonusRegen((n) => n + 1);
   416→    } catch {
   417→      toast.error("خطا در ارتباط با هوش مصنوعی");
   418→    } finally {
   419→      setBonusLoading(false);
   420→    }
   421→  }

   552→  /** خروجی CSV از دفتر اشتباهات — فایل UTF-8 با BOM برای اکسل */
   553→  async function exportMistakesCsv() {
   554→    if (!mistakeIds.length || exporting) return;
   555→    setExporting(true);
   556→    try {
   557→      const res = await fetch(`/api/questions?count=${mistakeIds.length}&ids=${mistakeIds.join(",")}&book=${bookId}`);
   558→      const data = await res.json();
   559→      const qs = (data.questions ?? []) as Question[];
   560→      if (!qs.length) {
   561→        toast.error("سؤالی برای خروجی یافت نشد.");
   562→        return;
   563→      }
   564→      const esc = (s: string) => `"${s.replace(/"/g, '""')}"`;
   565→      const rows = [
   566→        ["ردیف", "متن سؤال", "پاسخ صحیح", "دسته", "مبحث", "سطح"].join(","),
   567→        ...qs.map((q, i) =>
   568→          [
   569→            i + 1,
   570→            esc(q.text),
   571→            esc(q.options[q.answer] ?? ""),
   572→            q.category === "grammar" ? "گرامر" : "واژگان",
   573→            esc(q.scope),
   574→            esc(q.level),
   575→          ].join(","),
   576→        ),
   577→      ];
   578→      const blob = new Blob(["\uFEFF" + rows.join("\r\n")], { type: "text/csv;charset=utf-8;" });
   579→      const url = URL.createObjectURL(blob);
   580→      const a = document.createElement("a");
   581→      a.href = url;
   582→      a.download = "vision-one-mistakes.csv";
   583→      document.body.appendChild(a);
   584→      a.click();
   585→      a.remove();
   586→      URL.revokeObjectURL(url);
   587→      toast.success(`فایل CSV با ${qs.length.toLocaleString("fa-IR")} سؤال دانلود شد.`);
   588→    } catch {
   589→      toast.error("خطا در ساخت فایل CSV");
   590→    } finally {
   591→      setExporting(false);
   592→    }
   593→  }
