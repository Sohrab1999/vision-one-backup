## ۵٫۷) §U7 — «حالت بقا (مأموریت بی‌پایان)»

تا اینجا پایان مأموریت دو سر داشت: پیروزی بر رئیس (U4) یا اتمام ❤. U7 یک **قاعدهٔ اختیاری** به مأموریت اضافه می‌کند: «حالت بقا» — همان میدان، همان چهار حالت آموزشی، همان سلاح/نقشه/دشواری، ولی **بی‌پایان**: استخر سؤال بی‌امان reshuffle می‌شود، شمارهٔ موج بی‌سقف بالا می‌رود و رئیس واژه پس از هر منهدم دوباره برمی‌گردد. دور فقط با **اولین مرگ** تمام می‌شود و نتیجه در رکورد مستقل «survive» ثبت می‌گردد. بقا «حالت پنجم» نیست — یک لایهٔ قاعده روی چهار حالت آموزشی است (الگوی تپ ساده) تا صفر شکستگی در موتور آموزشی.

### قوانین سخت رفتاری U7 (قابل مذاکره نیستند)

1. **پایان فقط با اولین مرگ.** اتمام استخر دور را نمی‌بندد (deckPop از قبل reshuffle می‌کند)؛ منهدم رئیس هم دور را نمی‌بندد — بقا ادامه می‌یابد. تنها مسیرهای پایان: ❤ صفر یا خروج کاربر (نگهبان موجود).
2. **رکورد مستقل «survive».** جدا از چهار اسکوپ آموزشی؛ معیار مقایسه = امتیاز (سازگار با موتور کیت/توست رکورد)، همراهش موج و زمان ذخیره می‌شود (`SurviveRecord{score,waves,timeS}`). رکوردهای word/grammar/listen/chain دست‌نخورده می‌مانند.
3. **موج واقعی بی‌سقف، رفتار سقف‌دار.** بج/رکورد/تله‌متری موج واقعی را نشان می‌دهند؛ هر پارامتر رفتاری میدان (سرعت فرار، چیدمان، عمق سؤال) با `min(wave, WAVE_MAX)` می‌خواند — صفر جهش در ثابت‌های حرکت/فرار.
4. **رئیس دوره‌ای.** اولین ورود همان آستانهٔ مأموریت (موج ≥۴ = BOSS_WAVE)؛ پس از هر فروپاشی، ورود بعدی ۳ موج بعد (+SURVIVE_BOSS_EVERY). حین نبرد همان قوانین U4: پهپاد تعطیل، زمان چالش ۱٫۵×، خطا = چالش تازه، دفاع فعال قفس.
5. **قانون آموزشی دست‌نخورده (ADR-005).** بقا فقط قاعدهٔ پایان/موج/رئیس را عوض می‌کند؛ سؤال، هدف‌ها، SRS، کمبو و امتیازدهی همان موتور فعلی است.
6. **تله‌متری فقط افزودنی (ADR-002/006).** `detail.survive:boolean` کلید تازهٔ Attempt است؛ صفر تغییر/حذف کلیدهای موجود؛ `level` طبق ADR-006 همان `${scopeOf(mode,tap)}:${quality}` می‌ماند (مهاجرت تصمیم U8 است)؛ `detail.wave` در بقا = موج واقعی مانده.
7. **prefs فقط افزودنی (ADR-003).** کلید «visionone:game-pref:fps-survive» پیش‌فرض خاموش؛ بقا ترجیح ماندگار است (مثل تپ ساده) ولی رکوردش مستقل از حالت آموزشی/تپ در اسکوپ واحد ذخیره می‌شود.
8. **فریز و بودجه §۳.** صفر تایمر خام جدید — tick زمان بقا و همهٔ رویدادها در همان interval ۲۰۰ms رویدادگسسته (setState فقط روی تغییر)؛ فریز ADR-004 رایگان می‌ماند؛ بقا قاعدهٔ تصمیم است نه موجودیت رندر — هزینهٔ فریمی صفر.

### مشخصات فنی

- **ثابت‌ها (constants.ts):** `SURVIVE_BOSS_EVERY = 3` (فاصلهٔ بازگشت رئیس) · `SURVIVE_KEY = "visionone:game-pref:fps-survive"`.
- **survive.ts (خالص — بدون React/THREE):** `SURVIVE_SCOPE = "survive"` · `interface SurviveRecord { score: number; waves: number; timeS: number }` · `planWave(total): { real, eff }` — real = `floor(total/WAVE_SIZE)+1` (واقعی برای بج/رکورد/detail)، eff = `min(real, WAVE_MAX)` (برای bridge.wave/چیدمان/فرار/سؤال) · `bossDue(real, gate, active)` = `!active && real >= gate` · `nextBossGate(wave)` = `wave + SURVIVE_BOSS_EVERY`.
- **ارکستراسیون (index.tsx):** state `surviveMode` از prefs + `surviveRef` (الگوی latest-ref) + `nextBossGateRef` (مقدار اولیهٔ BOSS_WAVE، ریست در start) + `surviveSec` tick یک‌ثانیه‌ای در interval موجود با فرمول elapsed کیت (منهای pausedAccum — ساعت همیشه‌درست حین توقف). advanceImpl: موج واقعی برای setWave/maxWave/اعلام + موج اثرگذار برای bridge و چیدمان و سؤال + `bossDue(real, gate, bossStageRef===0)`. فروپاشی رئیس در بقا: `bossDefeatedRef=true` + گیت تازه = موج جاری +۳ + بازگشت پهپاد (bossStage=0 — مونت تازهٔ FSM) + advance پس از ۱٫۵ث (بدون finish). finish بقا: `scope = SURVIVE_SCOPE` (به‌جای scopeOf) + `saveBest<SurviveRecord>{score,waves,timeS}` + `detail.survive=true` + همان مسیر صدا/توست رکورد کیت.
- **HUD:** هدر — بج موج در بقا «بقا · موج n» (آیکون Flame کهربایی) جای «موج n»؛ تمام‌صفحه — «◆ بقا mm:ss» (زمان زندهٔ دوام، tick گسسته). نتیجه — عنوان «گزارش بقا» + ستون «موج بقا» + همان رتبه/ستارهٔ دقت. setup — ردیف «حالت بقا» بعد از «سبک کنترل»: چیپ + توضیح + «بهترین بقا: موج n · امتیاز».
- **آموزش:** گام یازدهم «حالت بقا» — پایان مأموریت ندارد؛ تا اولین مرگ دوام بیاور؛ رئیس هر ۳ موج برمی‌گردد.
