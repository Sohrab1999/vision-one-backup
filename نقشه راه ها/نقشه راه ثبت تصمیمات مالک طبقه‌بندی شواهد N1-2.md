## B) متن عین تصمیمات مالک (مصوب گفت‌وگویی ۲۰۲۶-۱۰-۲۳ — برای ثبت عیناً بدون تغییر)

> متن انگلیسی زیر عینِ تصمیم مالک است و در هر ثبت باید واژه‌به‌واژه حفظ شود. معادل فارسی صرفاً «ترجمهٔ همراه» است و باید با برچسب «معادل فارسی — ترجمه از عین مالک» درج شود تا عین/ترجمه مخلوط نشوند.

- **D1** = option (a): "interpret `NO-EVIDENCE` at the scope of a specific claim, based on a documented search that found no supporting evidence."
  - معادل فارسی: تفسیر `NO-EVIDENCE` در گسترهٔ یک ادعای مشخص، بر اساس جست‌وجوی مستندشده‌ای که هیچ شواهد پشتیبان نیافت.
- **D2** = option (a): "distinguish absence of supporting evidence in the searched documentation (`NO-EVIDENCE`) from ambiguity resolvable only through an authorized test (`UNVERIFIED`)."
  - معادل فارسی: تفکیک «فقدان شواهد پشتیبان در مستنداتِ جست‌وجوشده» (`NO-EVIDENCE`) از «ابهامی که فقط با آزمون مجاز حل‌شدنی است» (`UNVERIFIED`).
- **D3** = option (b): "analytically split multi-claim rows only when necessary and with explicit approval; do not automatically change the row count."
  - معادل فارسی: تفکیک تحلیلی سطرهای چندگزاره‌ای فقط در صورت لزوم و با تأیید صریح؛ تعداد سطرها به‌طور خودکار تغییر نمی‌کند.
- **D4** = option (b): "retain exactly one official label per item while preserving explanatory notes about mixed status and technical dependencies."
  - معادل فارسی: حفظ دقیقاً یک برچسب رسمی برای هر مورد، همراه با حفظ یادداشت‌های توضیحی دربارهٔ وضعیت مختلط و وابستگی‌های فنی.
- **D5** = option (c): "neither recover/transfer the original Phase 2 matrix nor formalize the reconstructed matrix at this time."
  - معادل فارسی: نه بازیابی/انتقال ماتریس اصلی Phase 2 و نه رسمی‌سازی ماتریس بازسازی‌شده در این زمان.

- [ ] **گام ۰ — پیش‌پرواز فقط‌خواندنی (تکرارشونده، الزامی پیش از هر تغییر):** شاخه/HEAD کامل + `git ls-remote backup refs/heads/main` + برابری با HEAD + `git status --porcelain=v1` + `git stash list` + sha256 هوک (`ee679bc1…`) + شمارش auto-commitهای جدید پس از `c74fd06…` + بازخوانی کامل این نقشه و دو سند هدف + تطبیق مبنا. هر مغایرت تبیین‌ناپذیر = توقف (BLOCKED) و گزارش.
- [ ] **گام ۱ — کنترل یکتایی (فقط‌خواندنی):** grep عنوان هر دو پیوست §C در دو سند هدف = **صفر** (نشان‌دادن عدم ثبت قبلی)؛ تعیین متن دقیق نهایی افزوده‌ها از §B/§D/§E همین نقشه — بدون افزودن محتوای بیرون این نقشه.
- [ ] **گام ۲ — (گام اجرایی مستقل ۱) پیوست D1–D5 به سند ممیزی:** افزودن بخش پیوستی با عنوان لنگر §C-۱ در انتهای سند — فقط افزاینده (+N/−0)، دقیقاً یک‌بار؛ محتوا = تاریخ + عین §B + جدول §D + بندهای §E.
- [ ] **گام ۳ — (گام اجرایی مستقل ۲) پیوست رکورد D5 به نقشهٔ ثبت مستندات فاز ۳:** افزودن بخش پیوستی با عنوان لنگر §C-۲ در انتهای سند — فقط افزاینده، دقیقاً یک‌بار؛ محتوا = عین D5 + سه اثر §C-۲ + ارجاع به پیوست سند ممیزی.
- [ ] **گام ۴ — (اختیاری — فقط با تصریح مالک در دستور اجرا) ورودی `worklog.md`:** append یک‌بار با الگوی موجود (`---` · Task ID · Agent · Task · Work Log · Stage Summary) و شناسهٔ پیشنهادی `N1-2-owner-decisions-d1-d5-record` — بدون بازنویسی ورودی‌های پیشین.
- [ ] **گام ۵ — مرور diff و کنترل stage:** `git diff --check`؛ تأیید diff فقط فایل‌های مجاز همان گام و فقط افزاینده (+N/−0)؛ بازخوانی کامل متن ویرایش‌شده (گیراندازی خطاهای RTL — درس §۶ نقشهٔ ۳-ه-۲C: ویرایش RTL دسته‌ای با MultiEdit ممنوع)؛ stage صریح **فقط مسیرهای صریح فایل‌های مجاز همان گام** — `git add -A` ممنوع مطلق؛ بدون stage `tool-results/*` · `.zscripts/dev.pid` · `db/custom.db`؛ `git diff --cached --check` + مرور نهایی staged diff.
- [ ] **گام ۶ — کامیت و انتشار:** کامیت توصیفی «docs only» با ذکر دامنهٔ دقیق (مثلاً «record owner decisions D1–D5 — appendix only»)؛ push به ریموت موجود `backup` شاخه `main` با گردش‌کار جاری پروژه؛ **راستی‌آزمایی انتشار = مشاهدهٔ مستقیم `git ls-remote backup refs/heads/main` برابر SHA کامیت جدید** («کامیت محلی = منتشر» هرگز فرض نمی‌شود) + `git merge-base --is-ancestor <SHA جدید> <tip ریموت>` در صورت امکان.
- [ ] **گام ۷ — راستی‌آزمایی پس از تغییر:** sha256 هوک بدون تغییر؛ `git show --stat --oneline HEAD` = فقط فایل‌های مجاز؛ grep لنگرهای §C: هر عنوان پیوست = دقیقاً ۱؛ شمارش چهار برچسب رسمی در دو سند هدف بدون کاهش/تغییر؛ اعداد عین دست‌نخورده؛ بررسی auto-commit جدید (در صورت وقوع: فقط گزارش صادقانه — بدون reset/amend/force-push)؛ ثبت وضعیت نهایی درخت به‌طور صادقانه.
- [ ] **گام ۸ — گزارش نهایی و توقف کامل:** گزارش شواهد به مالک (فایل‌های تغییر یافته، SHA محلی/ریموت، نتایج grep، تأیید صریح عدم انجام اقدامات ممنوع) ← **توقف کامل — انتظار دستور بعدی مالک.**

> **یادآوری:** گام ۲ و گام ۳ دو گام اجرایی مستقل‌اند — مالک می‌تواند هر یک را جداگانه (در نوبت‌های جدا) مجاز کند. هیچ گامی مجوز اجرای آزمون، فراخوانی runtime یا مجوز جدید نیست. تیک‌زدن هر گام فقط با شواهد واقعی همان گام.

## H) معیارهای پذیرش تغییرات (قابل راستی‌آزمایی — برای گام‌های اجرا)

- [ ] **فقط‌افزاینده:** diff هر فایل مجاز فقط افزودن خالص است (+N/−0)؛ متن موجود هر دو سند هدف بیت‌به‌بیت دست‌نخورده.
- [ ] **exact-once:** پیش از اجرا شمارش هر لنگر §C = صفر؛ پس از اجرا = دقیقاً ۱.
- [ ] **عین تصمیم مالک:** پنج متن انگلیسی §B واژه‌به‌واژه در پیوست هدف ۱ حاضر؛ معادل فارسی با برچسب «ترجمه» جدا از عین.
- [ ] **تفکیک سه‌لایه:** جدول §D در پیوست حاضر؛ هیچ قاعدهٔ رسمی لایه ۲ بازنویسی نشده؛ هیچ آیتم لایه ۳ وارد هیچ سندی نشده.
- [ ] **حفظ برچسب‌ها:** چهار برچسب رسمی بدون تغییر؛ شمارش `NOT PRE-AUTHORIZED` (چک‌لیست/اسناد) و `NOT APPROVED` (U5/U6) بدون کاهش؛ برچسب «یافتهٔ گزارش ممیزی» دست‌خورده.
- [ ] **وضعیت ماتریس:** گام ۲ §D نقشهٔ ثبت مستندات فاز ۳ همچنان تیک‌نخورده؛ هیچ فایل ماتریسی ساخته نشده؛ ماتریس بازسازی‌شده وارد هیچ سندی نشده.
- [ ] **بدون تغییر فایل نامربوط:** `git show --stat HEAD` فقط فایل‌های مجاز؛ هیچ چک‌باکسی (شامل Phase 0/Governance) تغییر نکرده؛ `db/custom.db` · `tool-results/` · `.zscripts/dev.pid` · `.git/hooks/` دست‌نخورده.
- [ ] **انتشار قابل راستی‌آزمایی:** SHA ریموت مستقیماً مشاهده‌شده و برابر کامیت جدید؛ وضعیت نهایی درخت صادقانه گزارش شده.

## I) شرایط توقف / BLOCKED (هر نوبت)

هر مغایرت گیت با مبنا (HEAD ≠ tip ریموت · درخت کثیف · stash ناخواسته · hook تغییرکرده · auto-commit نامرتبط جدید)؛ هر سند هدف مفقود یا تغییر یافته نسبت به مبنا؛ وجود قبلی هر پیوست (نقض exact-once)؛ هر نیاز به ویرایش بازنویسی‌گرانه یا تغییر بیرون §C؛ هر ابهام در متن تصمیمات §B؛ هر فشار برای پذیرش پسینی، ارتقای شواهد، رسمی‌سازی ماتریس بازسازی‌شده، بستن مورد باز، یا اجرای آزمون با استناد به این نقشه ← **توقف فوری و گزارش به مالک، بدون اقدام اصلاحی خودسرانه.** هیچ بدل‌سازی، هیچ آزمون ابداعی، هیچ تغییر کدی.

## وضعیت پس از ایجاد این نقشه (شمارش صادقانه)

- اجرای تازه: **صفر** — فقط همین فایل ایجاد شد (untracked، بدون stage/commit/push به موجب دستور مالک برای این نوبت)؛ هیچ سند/برچسب/چک‌باکس/worklog/کد/runtime دیگری تغییر نکرد؛ صفر HTTP/curl/probe (شامل `/api/health`)؛ صفر بازرسی runtime/کد/کش/پایگاه‌داده/شمارنده؛ `tool-results/` باز نشد.
- هر پنج گام §G و همهٔ معیارهای §H باز و تیک‌نخورده‌اند — اجرا فقط با دستور صریح مالک، گام‌به‌گام.
- هیچ مورد بازی بسته نشد؛ هیچ مجوزی استنتاج نشد؛ «فاز ۳ کامل» یا «N1-2 کامل» اعلام نشد.
- مانع هنگام ایجاد: **هیچ**.
