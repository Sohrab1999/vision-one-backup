## ۲ — دامنهٔ مجاز اجراشده (و همین‌ها و بس)

دوازده نقطه، فقط در `src/lib/offline-queue.ts` (+۶۹/−۲۹):

1. **سربرگ مستند** — بند «توقف پردازش پس از سقف (مرحلهٔ ۳)» + بند «قرارداد وضعیت».
2. **کامنت `QueueItem.tries`** — رفتار مرحلهٔ ۳ اضافه شد.
3. **نوع `QueueStatus`** — فیلد `cappedHead: boolean` با docblock (قرارداد داخلی؛ بدون export جدید).
4. **docblock `MAX_TRIES`** — توقف پیش از ارسال + انتشار `cappedHead`؛ G4 همچنان باز.
5. **snapshot اولیه** — `{ pending: 0, online: true, cappedHead: false }`.
6. **`emit()`** — `cappedHead` به‌عنوان سرصفٔ واقعی محاسبه، در مقایسه لحاظ و هنگام تغییر منتشر می‌شود؛ هویت snapshot در نبود تغییر پایدار می‌ماند (useSyncExternalStore).
7. **`rebuildSnapshot()`** — بازسازی شامل `cappedHead`.
8. **کمکی `normalizeTriesValue(value: unknown)`** — یک قرارداد نرمال‌سازی مشترک مرحلهٔ ۱ (readStorage، bumpTries، گیت، `cappedHead`).
9. **کمکی `isHeadCapped()`** — شرط مشتق‌شده روی سرصفٔ واقعی؛ صف خالی → false؛ هیچ تغییری در آیتم‌ها.
10. **`readStorage`** — همان نرمال‌سازی قبلی، اکنون از کمکی مشترک (رفتار تغییرنکرده).
11. **`bumpTries`** — همان نرمال‌سازی قبلی از کمکی مشترک؛ متن هشدار آستانه به‌روز شد («پردازش صف تا تغییر سرصف متوقف می‌شود») — همچنان شمارشی و بدون URL/query/توکن/دادهٔ شخصی.
12. **گیت توقف در `flushOfflineQueue`** + docblock آن — در ابتدای هر دور حلقه و پیش از fetch؛ `break` فوری: بدون fetch، بدون shift/عبور، بدون افزایش tries، بدون persist/توست اضافی؛ FIFO و نگه‌داری حفظ.
13. **`getServerSnapshot()`** — `{ pending: 0, online: true, cappedHead: false }`.

(شاخه‌های 2xx/408/429/4xx-قطعی/5xx/catch، `parseRetryAfterSeconds`، `pauseUntilMs`، `persist`، `enqueueOffline`/ظرفیت، `isQueueItem` و تریگرها دست‌نخورده‌اند.)

## ۳ — ممنوعیت‌های رعایت‌شده (فهرست تصدیق)

- هیچ قرنطینه/dead-letter نساخته شد؛ سیاست D8-c/D8-d/D9/G4 تعیین یا اجرا نشد.
- رفتار `Retry-After` و `pauseUntilMs` تغییر نکرد؛ مسئلهٔ ماندگاری آن پس از reload لمس نشد.
- enqueue، ظرفیت ۲۰۰، سیاست حذف سرریز، storage key و ساختار ذخیره‌سازی تغییر نکردند.
- هیچ API عمومی جدید، UI جدید یا export جدیدی به ماژول اضافه نشد (`QueueStatus` همچنان غیرعمومی است و مصرف‌کنندهٔ خارجی ندارد — با grep راستی‌آزمایی شد).
- مسیرهای محافظت‌شده (`tool-results/`، `.zscripts/dev.pid`، `db/custom.db`، uploads) بررسی یا تغییر نکردند.
- `git add -A`، force-push، amend و بازنویسی تاریخچه استفاده نشد؛ `main` و شاخه‌های قبلی لمس نشدند.
- فایل تست جدیدی داخل مخزن ساخته نشد؛ هارنس موجود `case.ts` **حتی یک بایت تغییر نکرد**.
